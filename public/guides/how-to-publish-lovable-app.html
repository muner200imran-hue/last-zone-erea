How to Publish a Lovable App (and Update It)

Building in Lovable is only half the job — your users need a live link. Publishing is free on every plan and takes about a minute.

Freelovable.app hosting on every plan
HTTPSset up automatically
1 clickto push new changes live

Publish for the first time

  1. Open your project and click Publish in the top-right corner, next to Share.
  2. Check the suggested Website URL (your-name.lovable.app) and change it if you like.
  3. Choose who can see the site, then click Publish again.
  4. Wait for the deployment to finish. Lovable shows your live link — open it and test it.

Your changes are not live? This is why

Publishing saves a snapshot of your app. Anything you build after that only shows in the preview inside Lovable — not on the live link.

To send new work live, click Publish, then Publish changes. Do this every time you finish a round of edits.

Change the address later

Go to Project settings → URL subdomain. Renaming the project does not change the address — the subdomain is a separate setting.

Want your own domain like example.com? See our custom domain guide.

Checklist before you publish

  • Click through every page in the preview and test forms and buttons.
  • Check the page title and description that will show on Google and when shared.
  • Test on a phone-sized screen.
  • If you use payments, finish the go-live checklist before taking real money.

Publish failed?

If an error blocks publishing, the Publish window offers Try to fix. Lovable reads the error and attempts a repair. See our build-errors guide if it keeps failing.

Frequently asked questions

Is publishing on Lovable free?

Yes. Publishing to a lovable.app address is free on every plan, with HTTPS included.

Why don't my latest edits show on the live site?

Publishing is a snapshot. Click Publish, then Publish changes, to send new edits live.

Can I change my lovable.app address?

Yes, in Project settings → URL subdomain. Renaming the project alone does not change it.

Does pushing to GitHub publish my site?

No. GitHub changes update the project and preview, but you still need to publish.

Can I unpublish?

Yes, you can take the site down from the publish settings at any time.
