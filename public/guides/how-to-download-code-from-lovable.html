Method 1 — GitHub

In the chat box, open the + menu, choose GitHub and connect. Your project syncs to a GitHub repository automatically.

Method 2 — ZIP download

On paid workspaces, open the Code Editor; at the bottom of the file list choose Download codebase.

Frequently asked questions

Can I download my Lovable code?

Yes via GitHub or ZIP.

Is the ZIP free?

Can I edit code outside?

Yes; changes sync back via GitHub.
