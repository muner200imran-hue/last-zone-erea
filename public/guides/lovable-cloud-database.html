Lovable Cloud Explained: Database, Login & Cost

Lovable Cloud is the built-in backend that lets your app save data, sign users in and store files — without setting up any outside service.

20 creditsmonthly Cloud grant (Free, Pro, Business)
~14 daysof daily database backups
Usage-basedbilling, not a fixed price

What's included

FeatureWhat it does
DatabaseSaves your app's data in tables Lovable creates for you
AuthenticationUser sign-up and sign-in
File storageImages, documents and uploads
RealtimeLive updates, e.g. chat
Backend functionsServer logic, e.g. sending email or calling AI

How you manage it

  • Browse, filter and edit records in the Cloud tools.
  • Export any table as CSV.
  • Review the security rules that protect each table.
  • Restore a daily backup (kept about 14 days).

How much does it cost?

Cloud usage is paid in credits based on what you use: database size and activity, stored data, traffic, file storage, compute and realtime.

Free, Pro and Business plans include a 20-credit monthly Cloud grant. Usage above that draws on your normal credits. Small apps usually stay inside the grant; busy apps cost more.

Tips to keep costs low

  • Don't store huge files you don't need.
  • Delete test data before launch.
  • Ask Lovable to load only the data a page shows, not everything.
  • Check usage regularly in your plan settings.

Frequently asked questions

What is Lovable Cloud?

Lovable's built-in backend: database, login, storage, realtime and backend functions in one place.

Is Lovable Cloud free?

Free, Pro and Business include a 20-credit monthly Cloud grant; usage beyond it uses normal credits.

Can I export my data?

Yes, export any table as CSV.

Are there backups?

Yes, daily backups kept for roughly 14 days.

Does reverting a version restore data?

No. Reverting restores code; database data stays as it is.
