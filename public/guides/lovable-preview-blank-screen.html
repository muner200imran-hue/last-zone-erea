Lovable Preview Blank or Not Loading? Try These Fixes

A white screen where your app should be is one of the most common Lovable problems. Most of the time it takes under a minute to fix.

Shift + Refreshrestarts the preview
Ctrl+Shift+Rhard refresh (Cmd on Mac)
1 promptasks Lovable to investigate

Fix it in this order

  1. Click Refresh above the preview.
  2. Still blank? Hold Shift while clicking Refresh to restart the preview.
  3. Hard-refresh the browser: Ctrl+Shift+R on Windows/Linux, Cmd+Shift+R on Mac.
  4. Ask Lovable in chat: “The preview is white, investigate and fix it.”
  5. If a recent change caused it, revert to the last working version from History.

What each message means

MessageWhat to do
Starting live preview… (for minutes)Check your internet; Lovable retries by itself
Live preview couldn't startCheck connection, click Try again, then Shift + Refresh
Live preview lost connectionClick Try again
Live preview stopped respondingClick Try again; if it returns, paste the exact message to Lovable

Common causes

  • A code error on the first page — Lovable can usually spot and fix it.
  • A browser extension or ad blocker stopping the preview — try a private window.
  • A weak or switching network (VPN, mobile hotspot).
  • An old cached copy — a hard refresh clears it.

Tell Lovable exactly what you see

Vague prompts waste credits. Say which page is blank, what you clicked before it happened, and paste any error text. A screenshot helps too.

Frequently asked questions

Why is my Lovable preview white?

Usually a code error or a stuck preview. Refresh, then Shift + Refresh, then ask Lovable to investigate.

Is my project lost?

No. Your code and history are safe; the preview just failed to show it.

Does the fix cost credits?

Refreshing is free. Asking Lovable to fix it uses normal credits.

The live site works but the preview doesn't?

Restart the preview with Shift + Refresh; the published site is a separate copy.

Nothing works — what now?

Revert to the last working version from History, then redo the change in small steps.
